LaunchMonitor an OceanSideVR project

Windows open where you launch them.

LaunchMonitor is a tiny Windows tray app for multi-monitor setups — especially Remote Desktop. Click an app on your second monitor and its window appears there, not back on the primary. No install, no admin rights, nothing to configure.

Download for Windows GitHub How it works

Why this exists

Windows decides where a new window opens, and in a multi-monitor RDP session that usually means the primary monitor — even when you clicked the icon on another screen. So every launch starts with dragging the window back where you wanted it.

LaunchMonitor watches where your mouse and keyboard activity happens, and when a new window appears it moves it to the monitor you launched it from. The window may flash on its original monitor for a moment before it moves.

How it works

1

Download and run

Grab the portable ZIP from Releases (win-x64 for ordinary PCs, win-arm64 for Windows on ARM). Extract it anywhere and run LaunchMonitor.exe. The .NET runtime is bundled.

2

Launch apps normally

Click or keyboard-launch an app from any monitor. For keyboard launches, leave the pointer on that monitor when you press the key.

3

It handles the rest

New windows move to the launch monitor on their own. Right-click the tray icon to Pause, enable Start at sign-in, or Exit.

Under the hood

ComponentWhat it does
LaunchMonitor.CoreLaunch timing and window-placement math — no Windows dependencies, fully unit-tested
TrayApplication / WindowWatcherTray icon, low-level input hooks, new-window show events

It respects your windows: already-open windows, dialogs, menus, tool windows, and minimized windows are left alone, and dragging or resizing a new window cancels any remaining move attempts. It preserves window size and maximized state, clamping placement to the target monitor’s work area.

No network requests, no telemetry. Nothing about your windows, typing, or app usage is recorded to disk — input history is 256 timestamps kept in memory. The only change it ever makes outside itself is an optional per-user startup entry, and only if you enable it.

Get it

  1. Download the portable ZIP from Releases (win-x64 or win-arm64).
  2. Extract it to any folder you can write to and run LaunchMonitor.exe.
  3. For RDP: run it inside the remote Windows session, on the computer running the apps, with RDP’s Use all my monitors option enabled so the remote desktop sees separate monitors.

The builds are unsigned, so Windows may show a publisher/reputation prompt on first run. Each logged-in session runs its own copy; a connection that presents one giant spanned monitor exposes no separate destinations to the app.

Platform scope

Built for multi-monitor Remote Desktop on Windows 10/11 and supported Windows Server versions. It also works on an ordinary local multi-monitor desktop.

Honest status

This is launch correlation, not a Windows shell replacement. An app that routes a launch through another process, reuses a pre-created window, or sets its own position later can behave differently. The acceptance checks in the README describe what still needs real-machine validation — they are not claimed to have passed.
